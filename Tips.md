# Tips and Tricks
### Tip 1:
If you want to run your python file directly, you can use this method:
1. Open your Code editor. (e.g. ```VS Code```, ```NotePad```)
2. Create a file using ```.bat``` extension. (e.g. ```run.bat```)
3. Put this code in your ```.bat``` file:
   ```bat
   @echo off
   cd "C:\Users\Windows\Documents"
   python main.py
   exit
   ```
   (N.B. put your folder location in line 2 and set your python file name in line 3)
4. Now double click your ```.bat``` file and your python file will run!!
