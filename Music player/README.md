If you want to run this code, follow the steps:
1. Before run, make sure you have the module ```pygame```,
   if you don't have ```pygame```, you can install it, open command prompot and type
   ```shell
   pip install pygame
   ```
1. Keep the ```music``` folder and ```Music_player.py``` in a same folder.
2. Create a existing folder and name it ```music```, same as ```music```.
3. Keep all of your songs to the ```music``` folder.
4. If you want to use another folder, write the folder location in code at lune 48:
   ```
   folder = "music"
   ```
