If you want to run this code, follow the steps:
1. Before run, make sure you have the module ```pygame```,
   if you don't have ```pygame```, you can install it, open command prompot and type
   ```shell
   pip install pygame
   ```
2. Create a existing folder and name it ```music```, same as ```music```. Make sure your ```music``` folder and ```Music_player.py``` is at same folder 
3. Keep all of your songs to the ```music``` folder.
4. If you want to use another folder, write the folder location in code at line 48:
   ```python
   folder = "music"
   ```
   replace it like:
   ```python
   folder = "C:\\Users\\Windows\\Music"
   ```
